1 · Getting Started

Expertir 4.0 is a desktop application developed by EPC Groupe. It centralises all stages of a drill & blast operation — hole design, explosive loading, initiation sequencing and report generation — into one workspace. Projects can be saved locally or synchronised with the Explore™ cloud platform.

📐

Design

Create, import and edit holes, front lines and markers on a 3-D mesh.

💥

Charging

Assign explosive products per hole, manage decks and inventory.

⏱

Sequence

Set up electronic or non-electric firing sequences and visualise timing.

📊

Reporting

Generate professional blast and drill-log reports.

☁

Explore™

Push and pull projects with the cloud for team collaboration.

🔄

Import / Export

CSV, DXF, STR, OBJ, Iredes, Polarex, Deswik, Daveytronic…

Click Open next to a blast in the list. If the main revision is missing, Expertir warns you and prevents opening.

1.5 · Saving a Project

Press Ctrl+S or click Save in the top bar. The first time you save a new project, a dialog asks:

  • Save locally — stores the project on your computer only.
  • Save on Explore — links the project to your Explore account. Fill in Site name, Project name, Zone name, Blast name and Planned date.

When leaving an open project, Expertir prompts you to save or discard unsaved changes.

2.2 · Hole Creation Tools

All creation tools are in the Creation sub-panel. They form a radio group — only one is active at a time. Click a button to activate; click again or press Esc to exit.

Before placing holes, set defaults in the Hole initial parameters group (also in the Creation sub-panel) and click Apply:

Parameter Unit Description
Spacing m Default distance between adjacent holes in a row
Burden m Default distance from the free face to the first row
Min Burden m Minimum allowed burden; the software warns if violated
Diameter mm Drill bit diameter
Inclination ° Angle from vertical (0 ° = vertical)
Length m Total hole depth
Bench Height m Height of the bench (used to compute toe positions)
Subdrill m Extra depth below the design floor
Floor Altitude m Absolute Z level of the bench floor

Single Hole Tool

Places one hole per click.

Click "Single" in the Creation sub-panelThe cursor changes to indicate the tool is active.
Review parametersCheck Inclination, Azimuth, Diameter, Length and Subdrill in the Hole parameters group. Click Apply if you changed anything.
Click in the Top View (or another 2-D view)A hole appears at that position immediately.
Continue clicking to place more holesClick Single again or press Esc to exit the tool.
ℹ
Min hole distance — The tool will not place a hole closer than the configured minimum distance to any existing hole head. Adjust this in the Hole parameters group.

Line Tool

Creates a straight row of evenly spaced holes in one drag gesture.

Click "Line" in the Creation sub-panel.
Verify Spacingin Hole initial parameters.
Left-click to set the start point, drag to the end, then release.Holes are placed along the line at the configured spacing.

Polyline Tool

Distributes holes along a multi-segment path you draw.

Click "Poly" (multiple-tool icon) in the Creation sub-panel.
Click successive pointsto define the path. Holes appear along the path at the configured spacing.
Double-click the last pointto finish and generate the holes.

Holes & Bench Tool

Generates holes together with a theoretical bench front (crest + toe lines). Useful for Open Pit projects.

Click "H&B" in the Creation sub-panel.
Configure the frontin the Theoretical Bench group: Bench Inclination (°), Bench Height Left/Right (m), Floor Level Left/Right (m). Check Left = Right to mirror both sides.
Choose the front shape: Straight, Inward curving, or Outward curving.
Click and dragacross the Top View. Crest and toe lines are created automatically alongside the holes.

Fan Tool

Creates holes radiating from a central point — typical in underground stope fan blasting.

Click "Fan" in the Creation sub-panel.
Configureangular spacing, burden and number of holes in the Fan Creation Criteria group.
Click in the Ring view(or Top View for stope) to set the fan's origin. Holes radiate outward at the configured angles.

Tunnel Hole Tools Tunnel only

Mass Editing

Select multiple holes (rectangle/polygon selection or Ctrl+click), then open Change Hole Parameters → Change Holes Geometries from the top-bar menu. Apply a single value to all selected holes for: Inclination, Azimuth, Diameter, Length, Subdrill, Bottom Altitude, Top Altitude, Category, or Rotate from toe. Leave a field blank to keep individual values.

Renaming Holes

Open the Rename tool from the top bar or the Tools sub-panel. Three modes:

  • Select — click a hole, type a name in the Hole name field.
  • Increm. — activate the tool, click holes or draw lines across the Top View; they receive sequential numbers. Double-click to stop.
  • Decrem. — same, counting down.

Configure Prefix, Reset numbering start value and Incremental steps in the Naming Tools panel.

Snap Options

Two snap options in the top bar under the Snap menu:

  • Snap hole's head to ground surface — the collar is automatically placed on the imported terrain mesh when creating or moving holes.
  • Snap hole's toe to toe-snapping object — the toe is snapped to a designated snap mesh (e.g. a toe-line surface).

Importing a Generic CSV File

Click Import → Holes, browse to your file and click Open.
Set the separator(comma, semicolon or tab). Tick Header is first row if the first line contains column names.
Set Lines per hole— usually 1. Set to 2 or more if a single hole spans multiple rows.
Map the columns— click each column header and assign a role: Id, Start E/N/Z, End E/N/Z, Inclination, Azimuth, Length, Diameter, or GPS (Lat/Lon/Alt).
Set EPSG codes— enter EPSG (In) for the file's coordinate system and EPSG (Site) for the project's system if they differ.
Validate then confirm— click the validate button; a green "Success" confirms the mapping is valid. Click Confirm to import.
⚠
Always validate the column mapping. Wrong EPSG codes can place holes thousands of kilometres from the site.

Importing a DXF File

The DXF import dialog shows each geometry type found (faces, polylines, lines, points) and lets you choose what to import each as:

  • Import as terrain — choose terrain type: Ground, Gallery, Stope, or Toe snap.
  • Import polylines / lines / points as holes — each element becomes a hole.
  • Import polylines as deviations — for deviation paths of existing holes.
  • Import points as markers.
  • Import as laser profiles.

Also set Unit (Metres / Millimetres) and Coordinate system (Georeferenced / Local) before clicking Import.

Creating a Polyline

Click "Polyline" in the top bar(or from the Lines & Markers sub-panel).
Click in the viewto add successive vertices. The line is drawn live as you move the cursor.

Markers

2.6 · Terrain & Mesh

A 3-D surface mesh enables head/toe snapping, blast volume calculation, and visual context in the 3-D view.

Importing a Terrain

Drag an .obj or .dxf file into the view, or use Import. Only one terrain mesh per blast. If one already exists, you are asked to replace or cancel.

⚠
Distance warning — If the mesh is more than 1 km from the site origin, Expertir asks for confirmation. Beyond 50 km, it is strongly recommended to create a new project.

Display Modes

Mode Description
Texture Shows the mesh with its original colour texture (if the OBJ has a .mtl file)
Normal Map Enhanced shading using surface normals — good for visualising relief
Flat Single uniform colour; configurable in Settings
Wireframe Displays the triangle mesh edges — useful for quality checking

Creating a Mesh from a Laser File

Go to Tools sub-panel → Create a mesh from a laser file. Select your .las or .txt laser scan file. Expertir builds a surface from the point cloud.

Background Image

Import a georeferenced plan image (.pdf, .png, .jpg) via Import → Image. The Image Import Configuration dialog lets you position and scale the image with handles and sliders, then click Apply.

2.7 · Ring Planes UG Stope

Ring planes organise holes into vertical groups. Each ring has a Name, Azimuth, Dump angle and Colour.

Adding a Single Ring Plane

Click Ring → Single ringplanein the top bar.

Configure in the right panel: Name, Azimuth, Dump and Colour.

Adding Multiple Ring Planes

Click Ring → Multiple ringplanes. In the Rings configuration dialog, set Number of rings, Distance within rings (m), and Progressive change of orientation distance (m). Click Apply.

Opening a Ring in the Side View

2.8 · Tunnel Sections Tunnel

A section defines the tunnel face shape used by the tunnel hole tools.

Open the Sections sub-panelin the left panel → Section creation tools.
Choose a shape: Rectangle, Arched, Elliptical, or Saved (reuse a previous section).

2.9 · Slot Raise Module UG Stope

Designs the initial void-creating holes in an underground stope. Opens in its own window via the Slot Raise button in the top bar.

Click Slot Raise → Create Slot Raise.
Enter a namein the Slot raise name field.
Draw the rock polygon— in the Polygon list panel, click Add then click vertices in the view to outline the area to be blasted.
Set parameters: Swelling ratio (rock expansion factor), Depth (m), Max Angle (deg), Max Distance (m).
Click Auto Generate. Expertir computes the optimal hole layout.
Fine-tune manuallyusing the hole-editing tools. Use display options (Surfaces, Ratios, Distances) to verify the design.

Save as .json with Export Slot Raise; reload with Import Slot Raise.

2.10 · PPV Measurement Points

PPV (Peak Particle Velocity) quantifies ground vibration at sensitive locations. Expertir calculates the estimated PPV for each hole based on charge weight and distance.

Click the Measurement points list buttonin the top bar (ruler icon).
Click Add. A new row appears in the table.
Fill in the fields: Name, EPSG, X, Y, Z, K, α (Alpha), PPV max (mm/s).
Click Add to confirm.PPV is recalculated for all holes.

PPV values can be displayed as hole labels in all 2-D views.

2.11 · Blast Volume

Enable: in the Tools sub-panel, expand Blast Volume and tick Enable Blast Volume.
Calculate: click Calculate Blast Volume in the top bar. Expertir uses the terrain mesh and hole geometry.
Read results: volume (m³) appears in the Top View status bar and the Blast Volume widget.

Per-hole column and toe volumes can be displayed as labels. Configure via Terrain Sampling Ratio and Fast / Auto Mode in the Hole Volumes widget.

2.12 · Burden Trace

Visualises actual burden distances from each hole toe to the free face, flagging under- or over-burdened holes.

Click Burden Tracein the top bar (or right-click a hole → Trace Burden).
Configurein the Burden Trace Settings panel: Theoretical Burden (m), Min Burden, Max Burden.
Click Update.Coloured lines are drawn from each hole toe to the nearest free face.

3.2 · Top View

The primary plan view. Shows all holes projected onto the horizontal plane.

Status Bar

Permanently shows: Holes Count = X (Y selected) · Total drilled = X m · Min / Max / Average length · Blast Volume = X m³.

Hole Labels

Right-click an empty area → Display to toggle: Name, Inclination, Length, Diameter, Azimuth, Head/Toe Altitude, Initial Distance, PPV Calculated, Column/Toe Volume, Head/Toe Burden Distance, Head/Toe Spacing Distance, Programming Number, Deviation Order.

Grid

Toggle with the Grid button. In Grid Settings choose Theoretical or Geographical grid, scale, colour and position.

3.3 · Front View

Head-on view of the blast face. Best for checking inclinations and charge columns.

Toggleable Elements

Holes (head, toe, body) with labels · Crest and toe lines · All markers and polylines · Horizontal spacing lines and ring plane distance labels · Minimum profile contour · Virtual reference hole · Background image.

Navigation

Use ←/→ (or step buttons) to shift the viewing slice. Adjust step size with Increase/Decrease Front Horizontal Spacing Step.

3.4 · Side View / Ring View

Lateral cross-section. In Stope projects this becomes the Ring View showing one ring at a time.

Double-click a ring plane in the Top View to open it here. The active ring name is shown at the top of the view. If nothing is selected, the view prompts: "Double click on a ring plane in the top view to see it."

Toggleable Elements

Hole heads/toes/bodies with labels · Minimum profile cross-section · Graduations (ruler with configurable step) · Drill logs · Horizontal spacing and burden distances · Background image.

3.5 · Section View

Vertical cut perpendicular to the viewing direction. The current position shows as Distance to reference: X m. Navigate with Previous / Next Section buttons, or click the section indicator in the Top View. Click Reset to return to the origin.

4.3 · Loading a Hole

Select a holeby clicking on it. Charging info appears in the right panel (Loads tab).
Click Add productin the charging panel to open the product picker.
Browse the product tabsand click a product to select it.
Set charge parameters: Length (m), From top (m), and other fields in the charge detail widget.
Add a detonator— select a detonator product and add it to the appropriate deck level.

The Energy tab (next to Loads) shows the energy breakdown: toe/column shock & gas energies, global energy, powder factor, required energy.

Use Previous hole / Next hole buttons to step through holes without clicking in the view.

4.4 · Decks

A deck is a charge column separated from adjacent charges by stemming or air.

Select the target holes.
Click Decksin the top bar (Sequence Tools group). The Decks dialog opens.
Set parameters: Number of Decks, Number of detonators per deck, Interval between decks (ms). Tick Activate level connection if needed.
Click Apply.Settings are applied to all selected holes.

4.5 · Copy & Paste Load

Select the source holeand click Copy load in the charging panel.
Select the target holes.
Click Paste load.For ring plane projects, options include Paste to selected ring planes and Paste to selected ring planes with charges.

If target holes have different diameters, the Charge Paste Adapted dialog lets you choose which charge level to adapt to each hole's geometry.

4.6 · Inventory

The Inventory sub-panel (Charging tab) shows all products used with total quantities. Click Copy to clipboard or Export as TXT to share the data.

5 · Sequence Tab

5.1 · Overview

Click Sequence in the top bar. The sequence toolbar appears with these tool groups:

  • Non-electric / Electronic — switch technology (a confirmation dialog warns before converting).
  • Decks — configure inter-deck connections.
  • Connections — show/hide connector lines in the view.
  • Programming — detonator numbering tool.
  • Display — toggle per-hole display: None, Detonator ID, Timing, Status, With delta time, With distance.
  • Histogram — open the timing histogram.
  • Animation — start/stop firing simulation.

5.2 · Non-Electric Sequence

Settings

Click Settings in the sequence toolbar → Non-electric settings: Default detonator delay (ms), Default detonator number, Default connector colour, Connector delay per type (ms).

Working Modes

Mode How to activate What it does
Select Click the cursor button Select and inspect elements
Line Click the Line button Draw connector lines between holes by clicking them in sequence
Circular Click Circular mode button Connects holes in a closed loop
Linear Click Linear mode button Connects holes in a straight chain
V-Sequence Click V.Sequence button Creates a V-shaped timing pattern from a central row outward
Manual Increment Click Manual Incr. path button Click holes one by one to assign incrementing delays

Adding / Removing Connections

  • Add Nonel Connections → click two holes to link them.
  • Remove Nonel Connections → click a connector line to delete it.
  • Clear Nonel Sequence → removes all connections (confirmation required).

5.3 · Electronic Sequence

V-Sequence Tool

Click V.Sequencein the sequence toolbar.
Enter Deconfinement time (ms/m)— controls how fast the blast wave travels relative to burden distance.
Click a centre hole.The V pattern is generated outward. Tick Symetric to mirror both arms.
Adjustwith Reset (start over) or Manual Increment (fine-tune individual delays).

Programming Order Tool

Click Programming → Create a sequence order.
Activate the toolin the dialog.
Hover over holesto preview the cable path. Click a hole to stop the tool and assign sequential numbers.
Alternatively, use the polygon tool to draw a zone — all holes inside receive sequential numbers.

5.4 · Histogram & Animation

Histogram

Click Histogram in the sequence toolbar. The chart shows firing count per time window. Set Cumul. +/- (ms) to group nearby firings. Use it to verify no excessive simultaneous detonations (which would cause PPV spikes).

Animation

Click Animation (play button). Holes light up in firing order. Controls: Anim. speed (ms/s), Anim. at (ms) (jump to a time), Loop, Pause, Reset.

7.5 · Troubleshooting & FAQ

Expertir won't start / Licence Error

Ensure internet access. Expertir requires periodic online licence validation. If the problem persists after connecting, upload logs from the Help menu and contact support.

Holes appear far from the site after import

The EPSG code for the input file or the site is wrong. Re-open the import dialog, correct both EPSG fields and re-validate. Common mistake: using EPSG:4326 (WGS84 geographic, in degrees) when the file uses a projected system (UTM, Lambert, etc.).

Import fails with a parse error

  • Verify the separator matches the selection.
  • Check for blank lines or extra columns in the file.
  • For STR and laser files, look at the line number in the error message and fix the formatting there.

The terrain mesh is far from my holes

The OBJ or DXF file uses a different coordinate reference. Expertir warns at >1 km (confirmation needed) and >50 km (strongly recommended to create a new project).

Export fails

  • Check that the target folder is writable.
  • Close the file in any other application if it is already open.
  • Check available disk space.

Explore sync / export fails

  • Confirm internet connection and that Connected is shown top-right.
  • The blast must be open before exporting.
  • Save all changes first.
  • Export the main revision before sub-revisions.
  • If it persists, click Sync with Local to clear the cache and retry.

A sequence warning about minimum safety distance appears

Two or more holes fire too close together in time relative to their physical distance. Adjust delays to increase the time gap between those holes.

Daveytronic export validation errors

  • Hole names: ≤ 5 chars (DT4G) or ≤ 10 chars (DT5G); only A–Z, a–z, 0–9, -, _ and spaces.
  • Path letter must be A–R; PU serial number 1–9999.
  • No empty decks; max 9 decks per hole; 1 detonator/deck for DT4G, up to 9 for DT5G.

How do I send logs to support?

Top bar → Help menu → Upload Logs. You can also enable automatic log upload in Settings → Application → Enable upload logs.

7.6 · Glossary

Term Definition
Blast A complete explosive firing operation on a defined rock mass
Burden Distance from the free face to the first row of holes
Subdrill Extra hole depth below the design floor to ensure complete fragmentation at the toe
Stemming Inert material (drill cuttings, gravel) placed above the explosive column to confine gases
Deck A discrete explosive charge separated from adjacent charges by stemming or an air gap
Detonator Device that initiates the explosive; may be non-electric (shock tube) or electronic
Delay Programmed time between detonator firing and the next; controls fragmentation and vibration
Isochrone Line connecting holes that fire at the same instant; used to visualise blast timing
PPV Peak Particle Velocity — measure of ground vibration used for blast impact assessment
Revision A saved version of a blast project; multiple revisions can coexist under one blast
Ring Plane A defined plane through which UG Stope drill holes radiate from a single drill drive
Slot Raise Initial opening blast in a stope, creating the free face for subsequent rings
Mesh / Terrain 3-D surface model (OBJ, DXF, STR) representing the rock mass or pit floor
EPSG Coordinate reference system code; used to geo-reference the blast in real-world coordinates
