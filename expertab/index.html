1Application Overview

1.1 What is ExperTab?

ExperTab is an Android mobile application developed by EPC Groupe that digitalises field operations for drilling and blasting. It replaces paper-based workflows, giving site teams a real-time, connected tool for recording and validating every stage of a blast cycle.

1.2 Who is it for?

ExperTab is designed for field operators, drillers, loaders, and geologists working on blast sites. Each user is assigned one or more roles that unlock specific screens and capabilities.

1.3 Business Context

ExperTab integrates with the Explore back-office platform (EPC Groupe). Blast plans are created in Explore, downloaded on site via ExperTab, and field data is exported back to Explore at the end of each session.

2Installation & First Steps

2.1 Requirements

  • Android 8.0 (Oreo) or later
  • Minimum 2 GB RAM recommended
  • Active internet connection for login and export
  • Bluetooth enabled (for Polarex deviation measurements)

2.2 Installing the App

  1. Receive the APK file from your EPC Groupe administrator.
  2. On your Android device, enable Install from unknown sources in Settings → Security.
  3. Open the APK and follow the on-screen installation prompts.
  4. Grant all requested permissions (location, Bluetooth, storage).

2.3 Logging In

  1. Open ExperTab. The login screen appears.
  2. Enter your email and password (provided by your administrator via Keycloak).
  3. Tap Log in. On first login you may be prompted to change your password.
  4. The Home screen appears with your assigned blast plans.

2.4 Loading a Blast Plan

  1. From the Home screen, tap the Explore button.
  2. Browse available sites, zones, and blast plan names.
  3. Tap a blast plan to select and download it.
  4. The app returns to the Home screen — the blast plan is now available for all workflows.
Tip: Pull-to-refresh on the Home screen to sync the latest plans from the server.

3Drill

The Drill screen is used to record the actual drilling of each hole in the blast plan.

3.1 Starting a Drill Session

  1. Navigate to the Drill screen via the navigation drawer.
  2. A Drill Session dialog appears on first entry.
  3. Fill in the equipment type, operator name, and team.
  4. Tap Validate to create the session. The 2D blast map is then displayed.

3.2 Selecting a Hole

  1. Tap a hole on the map or use the search bar to select it by name.
  2. Review the planned depth and geometry in the data panel.
  3. Enter the actual drilled depth, water level, and any other required measurements.
  4. Data saves automatically as you work.

3.3 Hole Status

Set the hole status to reflect its real-world state. Tap the status selector in the hole panel and choose from:

  • DRILLED — hole drilled to required depth
  • TO_REDRILL — flagged for re-drilling
  • REDRILLED — successfully re-drilled
  • COLLAPSED — hole has collapsed
  • MISSING — hole could not be located

3.4 Drill Summary

  1. Tap the ⓘ icon in the toolbar when the session is complete.
  2. The Drill Summary dialog shows totals: drilled, collapsed, missing holes.
  3. Review and close the dialog. Data is already saved.

3.5 Adding a New Hole

  1. Tap the Add Hole button on the map screen.
  2. Enter the hole name, collar coordinates, planned depth, and geometry.
  3. Enable Consigned if applicable.
  4. Tap Save. The hole appears immediately on the map.

4Advanced Drilling

The Advanced Drilling screen extends the standard Drill workflow with additional data fields for more detailed borehole records.

4.1 Overview

Advanced Drilling follows the same navigation and session setup as standard Drill. The key difference is the data panel, which exposes additional fields for recording extended parameters beyond depth and status.

4.2 Extended Data Fields

Depending on site configuration, the advanced panel may include:

  • Drill bit diameter and wear
  • Penetration rate and time per hole
  • Air pressure readings
  • Any custom fields defined by your site administrator
Note: Available fields vary by site. Contact your administrator if expected fields are not visible.

4.3 Searching for a Hole

  1. Tap the search bar in the toolbar.
  2. Type the hole name or ID exactly as it appears on the map.
  3. The map scrolls to and highlights the matching hole automatically.

5Geology

The Geology screen is used to log lithology (rock type and quality) per hole depth segment.

5.1 Logging Lithology

  1. Navigate to the Geology screen via the navigation drawer.
  2. Tap a hole on the 2D blast map.
  3. In the lithology panel, select the rock material type for each depth segment.
  4. Data is saved per hole as you progress through the blast plan.

5.2 Mineralisation Data

  1. Tap a depth segment to open the Mineralisation dialog.
  2. Record additional rock quality data: mineralisation grade, hardness, or other site-specific parameters.
  3. Confirm to save and return to the lithology panel.

5.3 Excluding Segments

Mark a depth segment as Excluded if it falls outside the zone of interest. Excluded segments are visually differentiated on the panel and are not included in summary reports.

6Simple Loading

Simple Loading records basic explosive loading data per hole.

6.1 Starting a Delivery

  1. Navigate to the Simple Loading screen.
  2. A Delivery Info dialog appears — enter the truck ID and operator name.
  3. Tap Confirm to begin the delivery session.

6.2 Loading a Hole

  1. Select a hole from the map or the list view.
  2. Enter the quantity of bulk explosive, cartridges, or detonating cord loaded.
  3. Hole status updates automatically: LOADING as quantities are entered, FILLED when complete.

6.3 Assigning Detonators

  1. Select the detonator type and model from the drop-down.
  2. Enter the serial or lot number.
  3. Optionally record a Test Cup sample reference.

6.4 Delivery Summary

Tap the ⓘ icon in the toolbar to open the delivery summary panel, showing totals across all loaded holes in the current session.

7Advanced Loading

Advanced Loading provides full QA/QC validation of explosive deliveries including MEMU machine integration and per-product quantity tracking.

7.1 QA/QC Workflow

  1. Navigate to the Advanced Loading screen and confirm delivery details.
  2. Select a hole from the map. The panel shows planned vs. actual quantities per product.
  3. Enter the actual loaded quantity for each product using the +/− buttons or direct input.
  4. Assign detonators and record lot numbers per hole.

7.2 MEMU Integration

If a MEMU (Mobile Explosives Manufacturing Unit) is connected, loading data can be pushed to and pulled from the machine automatically.

  1. Enable Truck Mode in Settings and enter the MEMU IP address and port.
  2. Tap Connect in Settings to establish the TCP connection.
  3. In the Advanced Loading screen, data sync with the MEMU occurs automatically on hole selection.
Note: The tablet and MEMU machine must be on the same local network (e.g., the truck Wi-Fi hotspot).

7.3 Delivery Summary & Confirmation

  1. When all holes are loaded, navigate to the Advanced Delivery Summary screen.
  2. Review per-hole and total quantities, detonator assignments, and lot numbers.
  3. Tap Confirm Delivery to mark the blast plan as ready for export.

8Polarex

The Polarex screen records borehole deviation measurements using a Bluetooth Polarex probe.

8.1 Bluetooth Connection

  1. Ensure Bluetooth is enabled on your Android device.
  2. Navigate to the Polarex screen.
  3. Tap the Bluetooth icon to scan for nearby Polarex probes.
  4. Select your probe from the discovered device list.
Tip: Enable Polarex Auto Connect & Export in Settings to automate this step on future sessions.

8.2 Taking Measurements

  1. Select a hole on the map.
  2. Lower the probe into the hole to the first measurement depth.
  3. Tap Measure to record the azimuth and inclination reading.
  4. Repeat for each depth interval following the on-screen Measure Steps dialog.
  5. The deviation path is drawn on the hole diagram in real time.
  6. Tap Reset to redo measurements for a hole if needed.

8.3 Exporting DM4

  1. Once measurements are recorded, tap Export DM4.
  2. The DM4 deviation report file is generated and saved locally.
  3. Use the main Export screen to upload it to the Explore platform.

9Roles & Permissions

Access to each section of the app is controlled by roles assigned by a site administrator. Each role unlocks one or more navigation menu items. A single user can hold multiple roles simultaneously.

DRILLER
Menu: Drill
Standard drilling workflow — record hole geometry and progress.
ADV_DRILLER
Menu: Adv. Drill
Advanced drilling workflow with extended data fields.
GEOLOGY
Menu: Geology
Log lithology (rock type) data per hole depth segment.
SIMPLE_LOADING
Menu: Simple Loading
Record basic explosive loading per hole.
QAQC
Menu: Advanced Loading
Full QA/QC loading validation, MEMU integration, delivery summaries.
SEQUENCE_ONLY
Menu: Sequence
View the blast firing sequence (read-only).
POLAREX
Menu: Polarex
Measure borehole deviation using the Bluetooth Polarex probe.
Note: If a menu item you expect to see is missing, contact your administrator to verify your role assignments in the Explore back-office.

10FAQ & Common Issues

10.1 Login & Authentication

I enter my credentials but get a red error banner.
  • Double-check your email address (no extra spaces) and password.
  • Use Forgot password? to reset via the Keycloak web portal.
  • Ensure you have an active internet connection.
  • Contact your administrator if your account may have been deactivated.
The app redirected me to Login while I was working.
Your authentication session has expired. Log in again — all locally saved field data is preserved on the device.

10.2 Home Screen

The Home screen shows "No blast" even though blasts exist in Explore.
  • Pull down on the Home screen to refresh.
  • Tap Explore to manually browse and load a blast.
  • Check that your account is assigned to the relevant site in the Explore back-office.

10.3 Drilling Screen

A hole I tap on the map does not respond.
  • Zoom in to improve tap accuracy on dense plans.
  • Verify the hole is not in a locked status (FILLED, COLLAPSED, MISSING can block some actions).
The Drill Session dialog appears every time I open the screen.
Ensure you tap Validate (not dismiss) the first time it appears to create and save the session.
I cannot find a hole using the search bar.
The search matches the exact hole name. Check for extra spaces or letter-case differences.

10.4 Loading Screen

A hole is greyed out and I cannot enter loading data.
Holes with status MISSING or COLLAPSED are blocked from all loading changes. Use the Advanced Loading screen (QAQC role) to adjust a FILLED hole.
The MEMU connection fails in Advanced Loading.
  • Ensure Truck Mode is enabled in Settings.
  • Verify the MEMU IP address and port are correct.
  • The tablet and MEMU must be on the same local network.
  • Tap Connect again in Settings after correcting the address.

10.5 Polarex Screen

The Polarex probe does not appear in the Bluetooth device list.
  • Confirm the probe is powered on and in pairing mode.
  • Grant Bluetooth permissions to ExperTab in Android system settings.
  • Tap the scan icon again to refresh the device list.
Deviation measurements appear incorrect.
Ensure the probe is fully inserted to the correct depth before tapping Measure. Follow the on-screen Measure Steps dialog step by step. Tap Reset to redo measurements for that hole.

10.6 Export

The export fails with an error.
  • Check your internet connection and verify you are still logged in.
  • Try exporting a single blast to isolate the issue.
  • Use Export Database Dump in Settings and send the ZIP to support.

10.7 Settings

I changed the language but the app is still in the old language.
Language change is applied immediately. If it did not apply, reselect the language in Settings. A full app restart may be required on some devices.
The External GPS option does not appear in Settings.
External GPS is visible only when your site has the SHOW_GPS_EXTERNE flag enabled. Contact your EPC administrator.

11Hole Status Reference

Each hole carries a status reflecting its current state in the workflow. Status is shown by colour on the 2D plan map.

Status Meaning
PLANNED In the plan but not yet drilled
DRILLED Drilled to the required depth
REDRILLED Re-drilled after a previous issue
TO_REDRILL Flagged by the operator as needing re-drilling
ADJUST Geometry has been adjusted from the original plan
LOADING Explosive loading is in progress
FILLED Fully loaded with explosive
BLASTED Has been fired
MISSING Could not be located on site
COLLAPSED Has collapsed and cannot be used

13Glossary

Term Definition
Blast plan The set of holes, geometry data, products, and firing sequence for a single blast event
Hole A borehole drilled in the rock in preparation for loading and blasting
DM4 Proprietary file format used to exchange borehole deviation measurement data
MEMU Mobile Explosives Manufacturing Unit — a truck-mounted machine that produces and delivers bulk explosive on site
Polarex A Bluetooth borehole deviation probe used to measure the actual path of a drilled hole
Lithology The physical characteristics of rock (type, hardness, mineralisation) logged per hole depth interval
Bulk explosive Pumpable or pourable explosive mixture delivered by a MEMU or tanker
Cartridge Pre-packaged stick explosive placed manually into a hole
Detonator Electronic or non-electric initiator used to fire a loaded borehole
Det cord Detonating cord — a thin, flexible initiating element used alongside detonators
Explore The EPC Groupe web platform used to create blast plans and receive field data from ExperTab
Keycloak The identity and access management system used for user authentication
QA/QC Quality Assurance / Quality Control — the validation process for explosive deliveries
Session A work session tied to a specific blast plan and role (e.g., drilling session, delivery session)
Zone A geographic sub-division of a site, used to group blast plans
